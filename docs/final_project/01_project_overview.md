# Customer Intelligence Agent

## 一句话介绍

面向企业增长场景的 AI Customer Intelligence Agent，通过用户行为分析、企业知识增强和多 Agent 协作生成营销策略。

## 业务问题

传统流程通常是“用户数据分析 → 人工洞察 → 搜索企业经验 → 制定策略”，存在数据与洞察割裂、企业知识难以被模型有效利用、策略缺少可解释性和验证体系等问题。

## 产品目标

构建一个数据驱动、知识增强、策略可解释、结果可评估的 AI 营销智能助手，打通从消费数据到营销策略和自动评估的完整链路。

## 最终验证范围

3 套 Benchmark、12,000 用户、45 个营销任务；最终 OverallScore 为 83.10，实验模式为 deterministic evaluation baseline。
