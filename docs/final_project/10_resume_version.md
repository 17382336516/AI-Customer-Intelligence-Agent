# Resume Version

- 设计企业级 Customer Intelligence Agent，搭建覆盖 3 套 Benchmark、12,000 用户和 45 个营销任务的多 Agent Evaluation 体系，最终 DataScore 93.43、InsightScore 100、OverallScore 83.10。
- 构建 User-level Lifecycle Classification 链路，将消费行为转化为 lifecycle tags 和可解释 evidence，实现 Lifecycle Recognition 与 Insight Grounding 100%。
- 优化 Enterprise Knowledge RAG，引入 Business Intent Routing、Query Expansion、Metadata Rerank 和 Knowledge Type Routing，实现 Recall@3 61.67%、MRR 73.33%。
- 设计 Strategy Requirement Planner、Knowledge Plan 和 Field-level Knowledge Trace，提升营销策略知识采用可追踪性，实现 Knowledge Adoption 68.33%。
- 建立规则化 Failure Analysis，能够定位 Data Mapping、Lifecycle、RAG Recall 和 Strategy Coverage 的具体失败原因。

说明：项目指标来自 deterministic evaluation baseline，不代表企业上线效果、GMV、收入或真实转化率提升。
