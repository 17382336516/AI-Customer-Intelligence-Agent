# Resume Versions

## Version A：AI 产品经理 / AI Evaluation 方向

- 设计企业级 Customer Intelligence Agent，搭建 Data、Insight、Knowledge、Strategy 四层 Multi-Agent 链路及 Evaluation Framework，覆盖 3 套 Benchmark、12000 用户、45 个营销任务，实现 OverallScore 83.10。
- 设计 D/I/K/S 分层指标、Golden Label、Artifact Persistence 和 Failure Analysis，使 Agent 输出可复现、可解释、可诊断；DataScore 93.43，InsightScore 100。
- 优化 Enterprise RAG，引入 Business Intent Routing、Query Expansion、Metadata Rerank 和 Retrieval Artifact，实现 Recall@3 61.67%、MRR 73.33%。
- 设计 Strategy Requirement Planning 与 Knowledge Trace，建立 Knowledge→Business Concept→Strategy Field 验证链路，Grounding 平均 89.63%。

## Version B：增长/商业化产品经理方向

- 面向用户增长、召回、复购和活动运营场景，设计从消费行为分析到营销策略生成的决策辅助产品。
- 将用户生命周期、企业产品机制、营销案例和策略字段建立可追踪映射，支持产品、内容、促销、渠道和指标协同规划。
- 通过 3 套 Benchmark、45 个业务问题验证产品能力边界，并用失败案例定位 RAG 覆盖和策略约束问题。

## Version C：通用产品经理方向

- 设计数据驱动的 Customer Intelligence Agent，完成用户分群、生命周期洞察、企业知识增强和策略生成闭环。
- 搭建可复现的 Benchmark Evaluation 体系，基于真实指标驱动多轮产品迭代。
- 将不可解释的生成结果拆解为结构化字段、证据和失败原因，提升产品可控性。

以上版本不宣称 GMV、收入或真实转化率提升；量化结果均为离线 deterministic evaluation。
