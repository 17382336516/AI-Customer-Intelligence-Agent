# MVP 验收清单

## 数据与分群

- [x] CSV、XLSX、XLS 上传
- [x] 中英文字段映射
- [x] 缺失率、异常、覆盖率、可分析性评分
- [x] 重复、退款、负金额、无效时间清理
- [x] 商品与品类语义归一
- [x] 用户级 RFM 与行为特征
- [x] 可解释规则优先、KMeans 辅助
- [x] 样本量、份额、置信度和证据

## Multi-Agent

- [x] 1 个 Orchestrator + 3 个业务 Agent
- [x] LangGraph 共享状态与条件分支
- [x] 质量回退、分群提前结束、完整策略三条路径
- [x] 结构化 Agent 输入输出
- [x] 工具调用与审计事件
- [x] 无模型密钥确定性降级

## 输出

- [x] 人群名称、核心特征、行为证据
- [x] 动机、需求、替代解释和限制
- [x] 产品机会、机制、权益
- [x] 页面主题、视觉关键词、模块与主副标题
- [x] 每个人群 3 条 slogan
- [x] 每张策略卡的实验指标
- [x] 自动化 Evaluation

## 产品界面

- [x] 数据上传和示例数据
- [x] 数据质量仪表
- [x] 自然语言业务问题和策略目标
- [x] Agent 实时协作轨迹
- [x] 人群分布图
- [x] 策略卡、证据与页面方向切换
- [x] 风险与边界提示
