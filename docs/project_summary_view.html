AI Customer Intelligence Agent 项目简略总结

版本：本地测试版｜日期：2026-07-31

本项目是一个面向用户消费/行为数据的本地智能分析平台，核心目标是帮助业务使用者从上传数据中快速获得数据质量判断、人群结构、用户洞察和可执行营销策略。

一、项目定位

  • 使用者上传 Excel/CSV 后，系统自动完成数据体检、人群识别和可视化展示。
  • 点击智能分析后，系统调用已配置的大模型生成用户洞察和策略分析。
  • 历史结果保存到本地数据库，可在历史页面查看和删除。

二、整体流程

  • 上传数据：接收用户行为或消费明细文件。
  • 数据体检：检查缺失、重复、异常和可分析程度。
  • 人群识别：按品类、行为、金额、频次等聚合信号识别人群。
  • 模型洞察：生成具体人群画像、兴趣标签和预测兴趣。
  • 策略分析：生成简要策略、页面要素关键词和攒钱相关短文案。
  • 历史沉淀：保存每次洞察和策略记录，支持删除。

三、板块输入与输出

板块 输入 是否用大模型 输出
数据上传 Excel/CSV 文件 否 数据集记录、字段识别、行数
数据体检 上传后的原始数据 否 质量评分、缺失/重复/异常提示
人群识别 清洗后的聚合行为数据 否 人群名称、人数、占比、识别置信度
用户洞察 人群结果 + 业务问题 是 画像、具体标签、预测兴趣
策略分析 洞察结果 + 业务问题 是 简要策略、页面关键词、短文案、验证指标
历史结果 已生成分析记录 否 历史洞察/策略查看与删除

四、Agent 分工

  • Orchestrator Agent：判断分析路线并编排流程。
  • Data Agent：读取、清洗、体检和本地分群，不调用模型。
  • Insight Agent：调用千问模型生成用户画像、兴趣标签和兴趣预测。
  • Strategy Agent：调用千问模型生成简要策略、页面关键词和攒钱相关短文案。

五、当前关键规则

  • 人群占比表示该人群在样本用户中的比例。
  • 识别置信度表示系统对该人群划分结果的可信程度。
  • 模型输入只发送聚合证据，不发送原始交易明细。
  • 模型输出已限制长度，降低等待时间和超时概率。
总结：当前版本已经具备本地上传、本地数据分析、大模型洞察、大模型策略生成、历史保存和历史删除能力，适合用于测试和演示用户智能分析流程。
