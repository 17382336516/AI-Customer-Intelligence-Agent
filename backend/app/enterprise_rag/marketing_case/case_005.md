# 案例 005：余额宝 × 葫芦兄弟 IP 联名

## Source

- 资料链接：SocialBeta https://socialbeta.com/campaign/23746
- 发布时间：公开报道（IP 联名活动）
- 资料类型：case

> 说明：以下内容基于公开营销报道整理，仅保留活动目标、机制与可复用方向，不补充未披露的内部数据。

## 背景

余额宝借经典国漫 IP「葫芦兄弟」做年轻化 / 怀旧向联名，以国民 IP 拉近距离、激活社交传播。

## 业务目标

- 用国民 IP 降低品牌沟通门槛，触达年轻及家庭用户。
- 借怀旧情绪引发社交平台自传播。

## 目标用户

- 对葫芦兄弟有情怀的 80/90/00 后，及家庭亲子群体。

## 用户问题

- 金融产品如何借助文化 IP 做轻量化、低门槛的年轻化沟通？

## 用户洞察

- 国民 IP 自带话题与情感记忆，易引发代际共鸣与二创。

## 核心策略

- IP 联名：将葫芦兄弟角色 / 故事与余额宝"攒钱 / 守护"心智结合，做轻量化内容。

## 活动机制

- IP 联名物料 + 社交平台话题互动，引导用户参与与分享。

## 可复用策略

- 国民 IP 联名：用高认知度文化符号降低沟通成本、激活怀旧传播。
- 轻量化年轻化：以IP玩梗替代硬广，适配社交平台语境。

## 适用业务问题

- 如何做年轻化 / 破圈的品牌沟通？
- 如何用 IP 联名提升品牌好感？

## Agent 检索关键词

葫芦兄弟、IP联名、国民IP、怀旧、年轻化、社交传播、品牌好感
