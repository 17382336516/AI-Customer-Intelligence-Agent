# 案例 001：余额宝「小挣青年」（五四青年节）

## Source

- 资料链接：数英网 https://www.digitaling.com/projects/262814.html
- 发布时间：2023-05（数英奖参赛作品）
- 资料类型：case
- 品牌 / 广告主：余额宝；媒介代理：磁力引擎

## 背景

年轻群体理财意识攀升，下沉市场增速较快。余额宝已占据高线城市年轻人心智，转向下沉市场探索增量；但金融服务特殊性及下沉市场信息壁垒，使建立用户信任困难。五四青年节是品牌营销竞技场，用户对硬广疲态明显。

## 业务目标

- 社会热度：聚焦社会议题引发全民讨论。
- 用户共鸣：嫁接品牌态度，提升圈层认同。
- 效果转化：链接情绪价值，承接流量转化。

## 目标用户

- 三四线及以下城市、在老家或大城市打拼的青年。
- 关注"赚钱"、对"快挣大钱 vs 慢慢挣小钱"反差易产生认同，偏好真实普通人故事。

## 用户问题

- 年轻用户对理财广告信任度低，传统曝光难引发共鸣。
- 下沉市场信息壁垒高，品牌态度难触达。

## 用户洞察

- 小镇青年认可"慢慢挣、挣小钱"的真实节奏，反感一夜暴富叙事。
- 普通人故事比头部达人更具同理心与可信度。

## 产品承载

- 余额宝品牌价值观暗线："人生余额是个宝"，传递长期储蓄与稳定积累。

## 核心策略

- 概念创新：用"小挣青年"一语双关，切"赚钱"关键词，制造 #小挣青年# 标签。
- 媒介适配：锚定快手（真实烟火气）+ 中国青年报（权威背书），降低下沉信任成本。
- 热点借势：围绕 #慢卷# #摆摊# 等社会议题造社交爆点。

## 活动机制

- 三方共创：余额宝 + 快手 + 中国青年报，五四节点推出短片及话题。
- 全链路资源：快手站内定制专题 / 热榜 / 开屏；站外微博微信出圈，媒体转载。
- 15 位快手真实青年（早餐店娇妹、烤肠桂桂、林区胡杨等）讲述朴素小挣故事。

## 内容方向

- 反差式短片：拒绝硬广，借五四聚焦 95/00 后内卷或躺平争议，呼"慢慢来也有未来"。
- 真实人物故事 + 朴素文案，诠释"小挣青年 = 每天小收益 / 按自己节奏积攒"。
- 双线叙事：明线"从小做起慢慢来"，暗线余额宝价值观。

## 可复用策略

- 贴切人群洞察 + 谐音 / 概念创新（如"小挣青年"），易自传播。
- 普通人达人共建，替代流量明星，显尊重与理解。
- 权威媒体 + 平台适配，降信任成本。
- 内容即营销：优质真实内容成广告一部分，破硬广疲惫。
- 热点借势：绑社会议题造标签，引自来水与热搜。

## 适用业务问题

- 如何提升年轻用户（尤其下沉市场）渗透率？
- 如何建立年轻用户对金融品牌的信任与认同？
- 如何做低硬广感的年轻化品牌沟通？
